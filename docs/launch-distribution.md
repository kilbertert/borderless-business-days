# Launch distribution kit

This is the prepared, non-published distribution kit for Borderless Business Days. It supports selective directory submissions and a later Product Hunt launch without mass-posting or paid engagement.

## Publishing boundary

- No directory or Product Hunt listing has been submitted by this kit.
- Use the canonical URL `https://borderlessbusinessdays.com/` without shortened or tracking links.
- Do not buy votes, pay a hunter or promoter, or request upvotes. Invite relevant people to try the product and leave honest feedback only.
- Keep platform account details, verification records, invoices, editorial correspondence, and real submission status in the private ledger, not this repository.

### Description

> Borderless Business Days combines public holiday calendars for up to eight markets. Count shared working days, calculate cross-border deadlines, find conflict-free windows, and export the result as CSV or ICS. The browser calculator is free; qualified teams can apply for a 30-day B2B API Pilot.

### First comment

> International deadlines often look valid until one market is closed. I built Borderless Business Days to treat multiple jurisdictions as one operating calendar. The free calculator runs in the browser and keeps the selected markets, dates, and result on the device. For teams that need the same logic inside an established workflow, there is a manually approved 30-day B2B API Pilot. I would value feedback from people planning payment, delivery, filing, or launch dates across countries: which markets, calendar assumptions, or audit details are hardest to keep consistent today?

### Pre-launch gate

1. The maker uses a personal Product Hunt account, not a company account, and the account has passed the platform's one-week posting wait.
2. The product page is usable, the canonical URL has no tracking parameters, and the prepared thumbnail plus two gallery images accurately reflect production.
3. The owner chooses a date only after a seven-day search and analytics baseline is recorded.
4. The maker can respond to comments during the full launch day and can claim the product page after launch.
5. The video remains optional. Do not rush a video upload; Product Hunt accepts a public YouTube URL only.

## Measurement and follow-up

Use the private distribution ledger maintained outside this repository for real submissions. It contains no credentials and is not a public source of truth.

Record one row per submission with the destination, date, canonical listing URL, free or paid plan, cost, status, next follow-up date, and public referrer label. Review the following aggregates each week:

- Search impressions, clicks, and landing-page performance in Google Search Console and Bing Webmaster Tools.
- Aggregate referrals and page performance in Cloudflare Web Analytics.
- Pilot page visits, qualified GitHub applications, cleared payments, and activated API keys using the existing private operational records.

Cloudflare Web Analytics does not log query strings. Do not introduce URL tracking parameters that encode calculator inputs, customer information, payment status, or secrets.
